# Opener

**Opener** is a minimalist, fully offline mobile application designed to browse, read, and edit local files directly from your Android device's internal storage. Built with React Native and Expo, Opener focuses on speed, simplicity, and a native file-explorer feel.

## Features
- **Local File Explorer**: Browse your device's files and folders using the native Android Storage Access Framework (SAF).
- **Smart Formatting**: Auto-detects and beautifully renders HTML and Markdown (`.md`) files.
- **Edit & Save**: Seamlessly edit text-based files and save changes directly back to your device storage.
- **Persistent State**: Automatically remembers your last opened directory and file.
- **Offline First**: No internet required, no cloud syncing, completely private.

## Tech Stack
- React Native (Expo)
- Expo Router
- Android Storage Access Framework (`expo-file-system`)
